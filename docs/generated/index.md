# Generated references

[Storage key/access-pattern catalog](db-schema.md) is extracted deterministically from TypeScript storage modules by scripts/generate-docs.mjs. It describes code patterns, not deployed resources or proposed Airs entities.

public-paths.txt is generated by npm run repo:check from reviewed manifest entries, including itself and the manifest, for explicit Git staging.

Do not hand-edit the database catalog; use npm run docs:generate. Generation executes no application code or provider call. npm run docs:check checks file links and freshness.
