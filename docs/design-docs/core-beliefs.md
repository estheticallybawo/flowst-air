# Core beliefs

Status: operating principles, 2026-10-04; not empirical findings.

1. Learning creates opportunities to retrieve, explain, reason and apply ideas after consuming a resource.
2. Airs develops verbal capability through contextual practice and evidence, without fixed intelligence labels.
3. Source import enables the journey; inquiry, teach-back and application carry the learning purpose.
4. NeuroMap separates mechanisms, strategies, techniques and evidence requirements. Agents use published contracts.
5. The backend owns authoritative state. Models propose; they cannot grant permissions or progression.
6. The learner controls approval, meaningful changes, help, pace, microphone use and learning information.
7. Source text is untrusted data. Validate references; label general knowledge and hypothetical scenarios.
8. Record actual responses/support. Separate observation, inference and recommendation, preserving uncertainty.
9. Implemented code, fixture checks, live checks and measured learning outcomes are distinct.
10. Start with stable documentation entry points and follow task-relevant links. Commit plans and truthful evidence.
