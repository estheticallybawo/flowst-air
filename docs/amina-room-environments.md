# Amina room environment assets

Generated with the built-in image generation tool on 15 October 2026 for the owner-requested Airs hackathon demonstration. Amina's existing `public/mascots/amina.png` was supplied as a style reference only. The rooms intentionally contain no people or characters; the existing animated character is layered over the image in the browser.

Create an inviting, softly rendered 3D study workspace in a premium family-animation world, matching the gentle rounded material language of the supplied character reference. A small sunlit reading room, warm pale oak desk mostly along the left edge, a few books and leafy plants, tall blue-framed window, sheer light curtains, soft sky-blue walls, comfortable upholstered chair mostly off to the side. Eye-level front view with believable perspective and depth. Leave the middle 45 percent visually open and calm so a waist-up avatar can be overlaid there. Distant desk, no foreground object crossing center. Soft natural daytime light, subtle physical texture, sophisticated not toy clutter. Palette cream, misty Flowst sky blue, light timber, muted green. No text, logos, watermark, UI, frames, characters or humans. Generate only the environment, NOT a mockup or avatar.

## Boundaries

These are generated illustration backdrops, not camera views, location recognition, or provider-rendered live video. Cosmetic selections use local sample Tides only. Amina's animation remains the illustrated expression atlas; the owner-only LemonSlice trial is a separate opt-in feature.
