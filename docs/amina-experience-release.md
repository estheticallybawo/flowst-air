# Airs experience release

15 October 2026. The completed demonstration UI has been integrated into the canonical `estheticallybawo/flowst-air` repository, not only the exported Kai experiment folder.

## Included

- A New Session picker with Study available and three clearly labelled future-mode previews.
- Distinct Study, interview, conversation-rehearsal, and language-practice demonstration screens.
- Only Airs companions Misu, Amina, and Kai; no full-Flowst future companion section.
- The owner-confirmed updated Misu and Kai portraits; the unused legacy Miro portrait is removed.
- Unbounded headings and Albert Sans body text, raised surfaces, and restrained frosted styling.
- Independent Animation Experience, Character Unlocks, and Milestones panels.
- Generated workspace, café, and garden backgrounds, with a night workspace treatment.
- Local sample Tide controls, milestone keepsakes at 5/10/25/50/100 sample Tides, and self-contained watermarked SVG downloads.

## Release boundaries

The newly requested face-only motion library is unfinished and excluded from this release. This release retains the previously completed illustrated Amina expression sample and static Misu/Kai cosmetic portraits. They are appearance demonstrations, not live agent-state or learning-assessment signals.

The private pilot LemonSlice/Agora service, owner authentication, SDK dependencies, API handlers, and provider settings are not copied into this public application. The live setup disclosure explicitly says calling is not enabled. No provider configuration or microphone request occurs when exploring the demonstrations.

Existing learner authentication, Study orchestration, voice transport, owned records, and backend configuration are preserved. No sample control awards actual Tides or changes saved learning progress.

## Verification

Fresh canonical checks pass: Nuxt typecheck, 483 unit tests across 53 files, the production build, documentation checks, and 12 desktop/mobile mode and experience cases. The browser checks cover navigation, independent panels, sample unlock thresholds, local clip controls, watermarked SVG downloads, and the absence of microphone requests or provider mutations. External font delivery remains a network dependency; functional browser checks block fonts deliberately.

The existing rewards branch also contains the Tide artwork positioning correction and geometry regressions. Its audio-capture changes are formatting-only; no voice transport behavior is changed by this release. Final public export hashes are regenerated after the owner-confirmed artwork changes and regression-test updates.

The private Flowst checkout contains independent uncommitted backend work. A cross-repository comparison reports those pre-existing mismatches; this UI release does not copy, overwrite, or publish that private work. The release snapshot pins only the two intentional standalone navigation/setup adaptations, with unchanged backend files retaining their existing verified hashes.
