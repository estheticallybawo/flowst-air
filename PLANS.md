# Execution plans

Engineering execution plans are first-class repository artifacts, distinct from Misu's learner-approved learning plans.

Record problem, scope, decisions, tasks, verification and dependencies. Mark proposed/active/completed status; distinguish implementation completion from live verification. Link evidence instead of copying private chat history.

See [index](docs/exec-plans/index.md), [Airs migration](docs/exec-plans/active/flowst-airs-orchestration.md), [completed foundation](docs/exec-plans/completed/source-and-misu-foundation.md), and [technical debt](docs/exec-plans/tech-debt-tracker.md).

Roadmap items do not automatically authorize implementation or publication. Determine current scope from the human request and applicable project rules.
